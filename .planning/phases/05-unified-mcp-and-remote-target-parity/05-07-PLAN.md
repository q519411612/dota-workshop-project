<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| TypeScript source to tracked executable runtime | Missing or stale imports can make the shipped MCP server unloadable or behaviorally divergent. |
| Build directory to git staging | Blanket promotion could retain unrelated generated output or confuse executable modules with forbidden candidate artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-07-01 | Tampering | source/runtime synchronization | mitigate | Isolated compiler output is compared byte-for-byte to staged blobs before an index-only load and invocation. |
| T-05-07-02 | Information Disclosure | generated build outputs | mitigate | Reachability allowlist, content boundary assertions, and deletion of undeclared outputs. |
| T-05-07-03 | Repudiation | runtime module versus candidate artifact distinction | mitigate | Tests and summary prove files are executable JS imports and contain no candidate/archive payload. |
</threat_model>
