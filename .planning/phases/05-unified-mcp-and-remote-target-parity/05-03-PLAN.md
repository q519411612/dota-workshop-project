| Host filesystem to identity-bound lifecycle | Links, reparse points, races, aliases, and hostile adapter results could escape source/candidate ownership. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-03-01 | Elevation of Privilege | caller-selected paths or credential fields | mitigate | Strict two-field schema and internal root/temp resolution. |
| T-05-03-02 | Tampering | source and candidate filesystem identities | mitigate | Non-follow classification, canonical containment, exclusive materialization, and repeated identity checks. |
| T-05-03-03 | Repudiation | prohibited-operation boundary claims | mitigate | Fixed mandatory versioned boundary object validated on every detail. |
| T-05-03-04 | Information Disclosure | candidate root and filesystem errors | mitigate | Opaque leases, inert callback evidence, safe relative identities, and stable category-only failures. |
</threat_model>
