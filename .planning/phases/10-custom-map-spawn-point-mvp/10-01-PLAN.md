- Add `PrepareCustomMapInputSchema`.
- Add `prepare_custom_map` to tool names, dispatcher, and server registration.
- Add tests that fail until schema parsing, dispatcher exposure, and server metadata exist.

### 2. Local and Fixture Map Preparation

- Create a focused map module for path construction, input validation, spawn-marker scanning, fixture copy, local Windows compile command construction, and result shaping.

- Add fixture tests for copy, spawn marker evidence, replacement behavior, and failure evidence.

### 3. Remote Map Preparation

- Add remote command script construction for copying the template `.vmap`, checking spawn entity strings, running `resourcecompiler.exe`, and returning JSON payload.
- Preserve command stdout, stderr, exit code, paths, logs, warnings, and target metadata.
- Add remote command-construction and remote failure tests.

### 4. Smoke Orchestration

- Add optional `customMap` input to `run_playable_smoke`.
- When present, create addon, prepare custom map, inspect addon, launch custom map, validate markers, and return compact transcript.
- Preserve default stock `dota` smoke behavior exactly when `customMap` is absent.
- Add smoke tests for ordering and default compatibility.

### 5. Documentation

- Update README with `prepare_custom_map` and `run_playable_smoke.customMap` examples.
- Update skill guidance and references for custom map preparation, compile evidence, spawn entity evidence, and binary map editing boundaries.
