# Plan: Local Install Simulation

**Status:** Ready
**Date:** 2026-07-07

## Implementation Approach

1. Add failing tests for package script exposure, successful simulation, missing dist entrypoint blockers, cleanup, path isolation, sensitive-material blocking, and environment non-mutation.
2. Add a local install simulation module that creates a temporary layout and copies the install-facing plugin files.
3. Reuse plugin structure validation concepts from the plugin verifier against the simulated layout.
4. Add sensitive-material scanning with category-only blocker output.
5. Add a built CLI verifier and package script.
6. Run targeted tests, build, and repository gates.
7. Record verification, independent review, and summary artifacts.

## Risks

- Copying repository content into a temporary path must not accidentally become a global install.
- Evidence should identify relative labels and categories without leaking private or secret values.
- Cleanup checks must prove the temporary simulation root is gone after the run.
