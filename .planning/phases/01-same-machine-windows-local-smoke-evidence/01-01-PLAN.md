# Plan: Same-Machine Windows Local Smoke Evidence

**Status:** Ready
**Date:** 2026-07-07

## Implementation Approach

1. Add failing Vitest coverage for the same-machine smoke evidence contract.
2. Implement the smallest verifier module that satisfies the artifact contract.
3. Add a built-output CLI and `verify:same-machine-smoke` npm script.
4. Add a same-machine Windows runbook with sanitized evidence instructions.
5. Run targeted tests, build, the new verifier command, and the repository gates.
6. Record verification, independent review, and summary artifacts.

## Risks

- Real same-machine Windows evidence may be unavailable in this macOS session. The verifier must record this as runtime evidence pending rather than passed.
- Sanitization checks must avoid echoing private values in blockers.
- Existing release gates scan repository text, so runbook wording must avoid credential-shaped examples and private machine paths.
