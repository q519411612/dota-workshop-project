# Phase 4 Plan: Remote Windows Target Support

**Status:** Ready for execution
**Scope:** REMT-01, REMT-02, REMT-03, REMT-04, LNCH-02

## Objective

Implement remote Windows command support for environment discovery and launch operations through SSH or PowerShell Remoting, preserving the same logical MCP tool contracts as local targets.

## Tasks

1. Add remote environment discovery through command execution and JSON parsing.
2. Add remote launch command construction for Workshop Tools and custom game launches.
3. Ensure remote command failures return explicit errors and do not fall back locally.
4. Register remote-capable handlers in MCP tools.
5. Document manual remote smoke validation without credentials.

## Verification

- `npm test`
- `npm run typecheck`
- `npm run build`
- Plugin and skill validation.

## Out Of Scope

- Storing remote credentials.
- Running real remote smoke tests without user-provided access.
