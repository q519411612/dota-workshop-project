# Safe Smoke Cleanup Controls Implementation Plan

> **For agentic workers:** REQUIRED: Use TDD for behavior changes. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explicit `cleanup_playable_smoke` MCP operation with dry-run and execute modes for addon-scoped Dota smoke process cleanup.

**Architecture:** Implement cleanup in a focused module that validates addon names, constructs local and remote PowerShell process scripts from one safety model, and delegates remote execution through the existing remote command adapter. Keep `run_playable_smoke` independent and document cleanup as a deliberate pre-run or post-run action.

**Tech Stack:** TypeScript, Node.js, Vitest, MCP SDK, PowerShell command construction for Windows targets.

---

## File Structure

- Create `src/cleanup.ts`: cleanup input type, validation, local/fixture execution, remote execution, PowerShell script construction, no-match parsing, result shaping.
- Modify `src/schemas.ts`: add `CleanupPlayableSmokeInputSchema` and exported type.
