## Must Haves

truths:
- Release dry run must validate addon names before filesystem reads or remote command construction.
- Release dry run must classify missing metadata and critical package files as blockers.
- Release dry run must scan text-like addon files for sensitive material with redacted evidence.
- Release dry run must return `ok: false` when blockers exist.
- Release dry run must warn that Steam login, encryption, and Workshop upload are manual/out of scope.
- Remote and local release dry run must share logical evidence categories.
