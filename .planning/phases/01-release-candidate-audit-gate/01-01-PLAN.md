# v1.6 Release Candidate Audit Gate Plan

## Objective

Add a local `verify:rc` gate that aggregates readiness commands and repository hygiene scans without touching Windows runtime targets or real publishing behavior.

## Files

- Create `src/rc.ts` for structured RC verification.
- Create `src/verify-rc.ts` for the CLI wrapper.
- Create `tests/rc.test.ts` for TDD coverage.
- Modify `package.json` to add `verify:rc`.
- Modify README and `docs/operator-runbook.md` for operator discoverability.
- Create `01-01-SUMMARY.md`, `01-VERIFICATION.md`, and `01-REVIEW.md` after implementation and verification.

## Work Items

1. Add failing tests for RC command aggregation, forbidden content scan failures, and package script discoverability.
2. Implement the smallest verifier that satisfies the tests.
3. Wire `npm run verify:rc` to built output.
4. Update docs so the RC gate appears before handoff.
5. Run targeted test, build, RC gate, full verification, and strict secret scan.
6. Perform independent review and record findings.
7. Commit and push only v1.6 files, leaving graphify freshness files uncommitted.

## Verification Commands

```bash
npm test -- tests/rc.test.ts
npm run build
npm run verify:rc
git diff --check
npm run typecheck
npm test
```

The verifier itself also runs command gates, so `npm run verify:rc` must be checked after `npm run build`.
