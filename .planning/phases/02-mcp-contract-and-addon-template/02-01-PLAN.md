# Phase 2 Plan: MCP Contract and Addon Template

**Status:** Ready for execution
**Scope:** MCP-01, MCP-02, MCP-03, MCP-04, ADDN-01, ADDN-02, ADDN-03, ADDN-04, ADDN-05, ADDN-06

## Objective

Implement a runnable TypeScript MCP server foundation with typed schemas, structured results, addon inspection, and deterministic minimal addon fixture generation.

## Tasks

1. Add Node/TypeScript project configuration, tests, and build scripts.
2. Define target, result, addon, environment, and remote command schemas.
3. Implement addon name validation, fixture addon generation, overwrite refusal, and addon inspection.
4. Implement target validation helpers that can run on macOS fixtures.
5. Add MCP server entry point and `.mcp.json` after the server can build.
6. Update plugin manifest to reference the MCP configuration.
7. Verify with tests, typecheck, build, plugin validation, and skill validation.
