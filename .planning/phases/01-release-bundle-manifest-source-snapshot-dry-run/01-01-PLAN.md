# Plan: Release Bundle Manifest / Source Snapshot Dry Run

**Status:** Ready
**Date:** 2026-07-07

## Implementation Approach

1. Add failing tests for manifest determinism, SHA coverage, boundary coverage, and sensitive material blockers.
2. Implement a small source snapshot manifest generator using deterministic filesystem traversal and SHA-256 hashing.
3. Add a built-output CLI and `verify:source-snapshot` npm script.
4. Run targeted tests, build, the new verifier command, and repository gates.
5. Record verification, independent review, and summary artifacts.

- `npm run verify:handoff`

## Risks

- The manifest must not include absolute repository paths.
- The sensitive scanner must not echo detected values.
- The command must stay dry-run only and avoid archive, signing, encryption, upload, or environment mutation behavior.
