### Blocking Integration Finding

`src/install-simulation.ts` copies the complete `skills/dota2-workshop-tools` directory. That directory includes `agents/openai.yaml`, but the sensitive scan only recognizes `.json`, `.md`, `.js`, `.ts`, and `.txt`.

An adversarial temporary fixture appended a synthetic credential marker to the copied YAML file. The verifier returned:

```json
{
  "ok": true,
  "blockerCategories": [],
  "cleanup": {
    "attempted": true,
    "removed": true
  }
}
```

This breaks INSTALL-05 and makes INSTALL-06 incomplete because its tests and recorded independent review did not detect the real copied-file format gap.
