<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime destination and generated script to transport process | Private host/user/root/script data must not cross into public command evidence. |
| Executor output to trusted detail | Exit status and stdout are hostile and may be malformed, contradictory, or incomplete. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-05-01 | Spoofing | zero-exit or supplied-success payloads | mitigate | Ignore narration and recompute all invariants through one normalizer. |
| T-05-05-02 | Tampering | stdout framing and nested JSON | mitigate | Require exactly one JSON object, strict version/shape, digest, counts, state, cleanup, and boundary consistency. |
| T-05-05-03 | Information Disclosure | target, command, logs, errors, stdout/stderr | mitigate | Separate private invocation types from fixed safe public evidence and reject unsafe output. |
| T-05-05-04 | Denial of Service | retry/fallback loops after uncertainty | mitigate | One invocation only; uncertainty is final and cleanup remains unknown. |
</threat_model>
