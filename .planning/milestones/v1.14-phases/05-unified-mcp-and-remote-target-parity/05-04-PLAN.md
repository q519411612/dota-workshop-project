## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-04-01 | Tampering | remote candidate assembly and hashes | mitigate | Target-native identity checks, streamed hashes, exact ledger/topology, and source-after comparison. |
| T-05-04-02 | Information Disclosure | stdout and script failures | mitigate | One compact JSON emission, suppressed pipeline output, safe codes, and no raw exception/root/content fields. |
| T-05-04-03 | Repudiation | remote cleanup outcome | mitigate | Finally-owned exact attempt/removal/absence evidence. |
| T-05-04-04 | Elevation of Privilege | transport binding credential or transfer behavior | mitigate | Existing destination configuration only, no credential prompts/stores, and no addon/candidate transfer commands. |
</threat_model>
