# Phase 9 Plan: Runtime Placement MVP

**Date:** 2026-07-06
**Status:** Ready

## Implementation Tasks

1. Add placement input types and validation in `src/addon.ts`.
2. Extend playable Lua rendering to accept optional placement and emit placement markers.
3. Add inspect evidence for placement configuration and marker support.
4. Extend schema/server/tool contracts for `create_addon` and `run_playable_smoke`.
5. Pass placement through local and remote addon generation using the shared renderer.
6. Extend `run_playable_smoke` marker generation when placement is requested.
7. Update README and skill references for runtime placement workflow.
8. Record verification and independent review artifacts.

## Test-First Slices

1. Add addon fixture tests for valid and invalid placement.
2. Add smoke fixture test proving placement markers are required when placement is requested.
3. Add remote command construction test proving remote creation receives placement-rendered Lua.
4. Add schema/dispatcher test coverage for placement input.

## Risk Controls

- Keep placement optional so existing smoke behavior is unchanged.
- Validate before writing or remote command construction.
- Use existing marker validation instead of adding a new validation subsystem.
- Keep generated Lua small and deterministic.

## Deferred Work

- Custom map spawn points.
- Hammer UI automation.
- Complex gameplay objectives.
- Unit, ability, item, or hero generators.
- Workshop publishing.
