# Phase 1 Plan: Plugin and Skill Foundation

**Status:** Ready for execution
**Scope:** PLUG-01, PLUG-02, PLUG-03, SKIL-01, SKIL-02, SKIL-03, SKIL-04

## Objective

Create a project-local plugin foundation with a valid manifest and a focused Dota 2 Workshop Tools skill that routes deterministic Workshop operations to MCP and keeps detailed workflow knowledge in references.

## Tasks

1. Create `.codex-plugin/plugin.json` with real metadata and only existing referenced components.
2. Create `skills/dota2-workshop-tools/SKILL.md` with trigger metadata, v1 scope, MCP usage guidance, and deferred workflow boundaries.
3. Create progressive references for addon layout, minimal template generation, launch flow, remote Windows control, and troubleshooting.
4. Add skill UI metadata in `skills/dota2-workshop-tools/agents/openai.yaml`.
5. Verify manifest paths and skill structure with local validation scripts and filesystem checks.
6. Record execution evidence in a phase summary.
