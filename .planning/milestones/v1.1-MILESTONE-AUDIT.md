## Cross-Phase Integration

- The plugin skill documents when to use MCP tools and keeps unsupported workflows deferred.
- `src/schemas.ts`, `src/tools.ts`, and `src/server.ts` expose the same logical MCP operations across fixture, local, and remote targets.
- Local and remote addon creation use shared renderers for playable, placement, objective, unit/ability scaffold, and preflight behavior.
- `run_playable_smoke` composes creation, optional custom map preparation, inspection, launch, and marker validation without hidden cleanup.
- `cleanup_playable_smoke` remains explicit and addon-scoped.
- Runtime validation continues to require log/console markers rather than launch success.
- Remote Windows validation has exercised cleanup, placement, custom map, objective, scaffold, and preflight paths without storing private target data.
- Documentation mirrors the implementation boundaries for Panorama, TypeScript-to-Lua, React Panorama, encryption, and Workshop upload.
